## What I've built

- **AI travel itinerary platform** ([DMCLounge AI](https://dmclounge.ai), Oslo, remote): lead development. Next.js + TypeScript frontend architecture, NestJS APIs, itinerary customization engine, Google Maps, email and WhatsApp integrations.
- **Smart-agriculture platform** ([Dimitra Technology](https://dimitra.io)): moved coordinate datasets to a spatial polygon architecture, turning millions of coordinate lookups into a much smaller set of spatial queries.

- **[Kharayo UI](https://ui.sumansharma.info.np)**: my React UI library built with Next.js, TypeScript, shadcn, Tailwind and Framer Motion.
